ساختار پیشنهادی پروژه Dot
=========================

index.html
    ساختار صفحه‌ها و اجزای HTML

static/css/styles.css
    تمام استایل‌های صفحه

static/js/
    main.js       نقطه شروع و راه‌اندازی ماژول‌ها
    config.js     تنظیمات API و محدودیت حجم فایل
    dom.js        دسترسی به عناصر HTML
    ui.js         پیام‌ها، جابه‌جایی صفحه‌ها و پنل حساب
    auth.js       ورود و ثبت‌نام نمایشی
    profile.js    پنل پروفایل و ویرایش نمایشی
    upload.js     انتخاب فایل، پیش‌نمایش و کنترل آپلود
    ocr.js        ارسال فایل به API و نمایش نتیجه OCR

app.py
    فایل بک‌اند Flask فعلی خودت را در ریشه همین پوشه نگه دار.
    این ساختار فرض می‌کند Flask از index.html در ریشه سرو می‌کند
    و پوشه static را با مسیر پیش‌فرض Flask ارائه می‌دهد.

نکته API:
    در static/js/config.js مقدار API_BASE_URL خالی است تا درخواست
    به همان دامنه‌ای برود که صفحه از آن بارگذاری شده است.
    اگر Flask روی دامنه/پورت جداگانه اجرا می‌شود، آدرس پایه را
    در همان فایل وارد کن و CORS را در بک‌اند تنظیم کن.

نکته مهم:
    ورود، ثبت‌نام و ویرایش پروفایل در این نسخه نمایشی هستند و اطلاعات
    حساب در پایگاه داده ذخیره نمی‌شوند. برای واقعی شدن آن‌ها باید
    API احراز هویت و ذخیره امن رمز در بک‌اند پیاده‌سازی شود.

فونت:
    اگر فایل digikala.woff2 را داری، آن را در assets/fonts قرار بده
    و مسیر @font-face در styles.css را به /assets/fonts/digikala.woff2
    تغییر بده. در بسته فعلی خود فایل فونت وجود ندارد.
