پروژه Dot — نسخه یکپارچه Flask
================================

ساختار:
- app.py: سرور Flask، API ورود/ثبت‌نام، پروفایل، دیتابیس SQLite و OCR
- index.html: رابط کاربری
- static/css/styles.css: استایل‌ها
- static/js/: کدهای جاوااسکریپت ماژولار
- dot.db: هنگام اولین اجرا خودکار ساخته می‌شود
- uploads/: پوشه آماده برای فایل‌های آینده؛ در این نسخه فایل آپلودی دائمی نگهداری نمی‌شود

اجرا:
1) محیط مجازی پروژه را فعال کنید.
2) وابستگی‌های OCR را در صورت نیاز نصب کنید: pip install -r requirements.txt
   Flask و OCR نیازمند کتابخانه‌های بالا هستند؛ sqlite3 همراه خود پایتون است.
3) Tesseract OCR باید جداگانه روی سیستم نصب باشد و داده زبان فارسی (fas) در آن موجود باشد.
4) اگر مسیر Tesseract در PATH نیست، متغیر محیطی TESSERACT_CMD را روی مسیر tesseract.exe تنظیم کنید.
5) اجرا: python app.py
6) مرورگر: http://127.0.0.1:5000

تنظیمات اختیاری ویندوز (PowerShell):
$env:TESSERACT_CMD = 'C:\Program Files\Tesseract-OCR\tesseract.exe'
$env:TESSERACT_LANG = 'fas'
$env:DOT_SECRET_KEY = 'یک-کلید-تصادفی-طولانی-و-محرمانه'

نکات:
- Flask به‌صورت خودکار تمام فایل‌های static را در /static/ سرو می‌کند.
- لینک‌های HTML و API نسبی هستند تا در مسیر استقرار /DOTai/ نیز قابل استفاده باشند، به شرطی که reverse proxy همان پیشوند را برای درخواست‌های Flask حفظ کند.
- ثبت‌نام و ورود با نشست Flask و هش رمز عبور انجام می‌شود. رمز عبور خام در دیتابیس ذخیره نمی‌شود.
- دیتابیس dot.db در پوشه اصلی ساخته می‌شود.
- OCR فقط متن را استخراج می‌کند؛ تصحیح و نمره‌دهی خودکار هنوز پیاده‌سازی نشده است.
- برای اجرای OCR به Tesseract و زبان فارسی نیاز است. اگر آن‌ها روی سیستم نصب نباشند، سرور بالا می‌آید اما endpoint OCR خطای واضح برمی‌گرداند.
- برای استقرار عمومی، حتماً DOT_SECRET_KEY را تنظیم کنید، HTTPS فعال کنید و از سرور WSGI مناسب استفاده کنید؛ app.run فقط برای توسعه محلی است.
